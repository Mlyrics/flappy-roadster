### How to Play

- **Desktop:**  
  - `Space` / `↑` — Lift  
  - `←` `→` — Steer  
  - `↓` — Descend  
  - `P` — Pause  

- **Mobile:**  
  Tap or hold the **THRUST** button to rise. Use the directional buttons to steer.

### Flight Modes

- **Cruise** — Roomy gaps, more forgiving  
- **Sport** — Faster flight  
- **Boost** — Tight gaps + high speed (hardest)

Clear gaps to score. Build combos for bonus points. Survive the lineup.
